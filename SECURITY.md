# SECURITY.md

## Reporting Vulnerabilities

If you discover a security vulnerability, please report it to the maintainer via [private email](mailto:admin@zorp.example). Do not disclose vulnerabilities publicly.

## Supported Versions

Only the latest stable release is supported. Older versions may have unresolved security issues.

## Response Expectations

All security-related issues will be addressed within 24 hours of confirmation.

## Disclosure Process

Vulnerabilities will be disclosed to affected users after a 30-day private reporting period.
