      Model settings

      The API key is held in memory only, for as long as this server process keeps running, and is never written to disk. Set ZORP_API_KEY in the server's environment to make it persist across restarts.

      Speech to text

      The microphone button appears once this is set. Recorded audio is sent to this address and nowhere else, so point it at a transcription server on this machine. whisper.cpp serves one: whisper-server -m ggml-base.en.bin --request-path /v1/audio --inference-path /transcriptions. Leave the field empty to switch voice input off. zorp never sends an API key here.
