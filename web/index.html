          Model settings

          The API key is held in memory only, for as long as this server process keeps running, and is never written to disk. Set ZORP_API_KEY in the server's environment to make it persist across restarts.

          Set up zorp

          zorp runs on your machine and talks to a model somewhere. It does not ship with one, so the first thing to do is say which model to use.

          • Local models work, and nothing you type leaves this machine when you use one.
          • A hosted provider needs a key. It is kept in the server's memory, never written to the config file.
          • You can change all of it later from the model button in the top bar.

          Where should the models come from?

          The key is sent to the zorp server on this machine and held in its memory for as long as it keeps running. It is never written to ~/.config/zorp/web.toml and never sent back to this page. Set ZORP_API_KEY where the server runs to have it survive a restart.
