# Support

Questions about configuration, setup, or "how do I" go to [Discussions › Q&A](https://github.com/aviskaar/zorp/discussions/categories/q-a).

Ideas that are not shaped enough to be an issue go to [Discussions › Ideas](https://github.com/aviskaar/zorp/discussions/categories/ideas).

Bug reports and specified work belong in the [issue tracker](https://github.com/aviskaar/zorp/issues). Use the bug report template.

Security vulnerabilities go to the address in [SECURITY.md](SECURITY.md). Private reporting is on.
