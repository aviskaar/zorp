# Support

Questions about configuration, setup, providers, or "how do I" go to
[Discussions › Q&A](https://github.com/aviskaar/zorp/discussions/categories/q-a).
A maintainer reads Q&A.

Ideas that are not shaped enough to be an issue go to
[Discussions › Ideas](https://github.com/aviskaar/zorp/discussions/categories/ideas).
Once an idea has a shape, it becomes an issue and the thread links to it.

What you found using zorp, such as a calibration run or a write-up, goes to
[Discussions › Research notes](https://github.com/aviskaar/zorp/discussions/categories/research-notes).

Bugs and specified work belong in the
[issue tracker](https://github.com/aviskaar/zorp/issues/new/choose). Pick the
bug report, reproducibility problem, or feature request form. The
`zorp-agent doctor` output the forms ask for prints no secret by design.

Security vulnerabilities are never reported in public. Follow
[SECURITY.md](SECURITY.md), which uses GitHub's private vulnerability
reporting.
